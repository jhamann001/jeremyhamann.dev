# Generic Apex Customer Account Transfer Request

This is a byte-for-byte copy of the blank template already held by CedarRidge's
Transfer Tracker. It is not a generated or completed client form.

- Source repository: `cedar-ridge-wealth/transfer-tracker`
- Source path: `public/form-templates/apex-customer-account-transfer-request.pdf`
- Source checkout inspected: `e33e43a8b5ea83ec07dd74fd990978821e0a0acf`
- Template introduced in source commit: `8cca5922a576d3edc0872fae1641aaa5fb88a1f1`
- SHA-256: `40316f1dc756d8d5cf07c014d9b7a53f3b9454244eb2ee157ddd70de00483630`
- Two pages, 95 AcroForm fields.
- `tracker-baseline-2026-09-17` is an internal capture label, **not** an Apex
  revision date or a claim that this is the latest official form. No verified
  official source URL or printed revision was available from the source package.

The pilot maps only page 1's receiving `ACCOUNT TITLE`,
`APEX CLEARING ACCOUNT NO`, and optional `SSNTAX ID NO`. All other fields,
including transfer selections, delivering-account fields, the conditional letter
of authorization, office-use fields, signatures and dates, remain blank.

Do not put a client address in `FIRM ADDRESS`, or copy the receiving title to
`ACCOUNT TITLE_2`: those are delivering-firm/account fields. Before sending,
CS must verify the template and custodian-specific requirements and complete the
remaining information using current client documentation. Tracker workflow and
routing logic is not part of this AoA draft mapping.
