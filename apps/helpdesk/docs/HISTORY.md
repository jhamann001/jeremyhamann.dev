# History

The desk was built in two waves of work against a written design: a contract per wave and a numbered
decision log. Comments in the code still mention them, as "Decision #96", "CONTRACT §14", "Wave A",
"slice B3" or "the build record". Those documents belonged to the original build and aren't part of
this repository; the comments carry their own explanation without them.

The invariants (I1–I15) are the exception: they are described in [`ARCHITECTURE.md`](ARCHITECTURE.md).
